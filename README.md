# Malhar Dighe — Static Resume Website

A static, semantic HTML/CSS/JavaScript portfolio for Malhar Dighe.

## Files

- `index.html` — page structure, content, metadata and structured data
- `style.css` — responsive editorial design
- `script.js` — mobile navigation, year and local food-enquiry storage
- `assets/` — place optional images or documents here

## Important note about the food enquiry form

This is a static website, so the form does **not** send data to a remote server.

Submitted enquiries are stored in the visitor's browser using `localStorage` and a confirmation message is shown. To receive enquiries yourself from the live website, a form backend/service will need to be connected later.

## GitHub → Vercel

1. Create a new GitHub repository, e.g. `malhar-resume-website`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open Vercel and import the GitHub repository.
4. For a plain static site, no build command is required.
5. Deploy.
